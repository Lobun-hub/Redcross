# Kirinyaga University Red Cross Society

This project is a modern, responsive website for the Kirinyaga University Red Cross Chapter. It is designed to strengthen community outreach, promote volunteering, and provide an easy digital platform for students and stakeholders to learn about the chapter, upcoming programs, events, and ways to get involved.

## Overview

The Kirinyaga University Red Cross Society has developed a new digital platform to improve its visibility, mobilize volunteers, and communicate its mission more effectively. The website highlights the chapter’s activities, values, and service initiatives while making it easier for people to connect with the organization.

## Key Features

- Responsive landing page for desktop, tablet, and mobile devices
- Hero banner with animated slides and progress indicator
- Mission and values overview aligned with the Red Cross Movement principles
- Programs and community service sections
- Event and volunteer opportunity highlights
- Team profile section for chapter leadership and members
- Gallery section with filterable categories
- Contact and inquiry form interface
- Social media and contact links for outreach and engagement

## Project Structure

- `index.html` – main page structure and content
- `styles.css` – page styling and responsive design rules
- `script.js` – interactive behavior such as slideshow, scroll effects, and form feedback
- `images/` – logos, photography, and supporting assets

## Installation

There are no complex dependencies or build steps required for this project.

1. Download or clone the project to your local machine.
2. Open the project folder in your preferred code editor.
3. Start a local web server from the project directory.

Example using Python:

```bash
cd "c:\HP Lobun\LOBUN\2026\Redcross"
python -m http.server 8000
```

Then open this in your browser:

```text
http://localhost:8000
```

You can also open the `index.html` file directly in a browser, though a local server is recommended for a smoother experience.

## Usage

### Home page
The homepage introduces the chapter and highlights its mission, values, and current outreach work. Use the navigation bar to jump between sections such as About, What We Do, Events, Team, Gallery, and Contact.

### About and mission
The About section explains the chapter’s purpose and the fundamental principles it serves. This helps visitors understand the society’s humanitarian focus and community impact.

### Programs and events
Use the Programs and Events sections to share activity updates, volunteer opportunities, awareness campaigns, first aid training, and other service initiatives. These sections are designed to keep students and community partners informed.

### Contact and join us
The Join Us and Contact options help users reach the organization for collaboration, volunteering, inquiries, or membership requests. The form button includes a simple interactive confirmation for user feedback.

### Gallery
The gallery displays visual highlights of the chapter’s work and events. Filters can be used to categorize items for easier browsing.

## Development Notes
